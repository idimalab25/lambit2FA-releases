lambit2FA для Linux — версия 1.1

Коды двухфакторного входа на вашем компьютере. Без учётной записи и без интернета. Коды хранятся зашифрованными; ключ лежит в связке ключей системы (GNOME Keyring или KWallet), а где её нет — в файле, привязанном к этому компьютеру и вашему пользователю.

Для обычных компьютеров (Intel или AMD, x86_64):
  lambit2FA-1.1-linux-x86_64.AppImage (38 MB)
  SHA-256: c982bbe2ab85bf8af552288a63b1adb8bcf5fb2a0e8bc75d0c6dfbb5195dcf6f

Для компьютеров на ARM (Raspberry Pi 4/5, виртуальные машины на Apple Silicon, aarch64):
  lambit2FA-1.1-linux-aarch64.AppImage (36 MB)
  SHA-256: d97fab86f6f6904dad798f2fcda40e7921978d4a3fc5f94ffc75072f4c279c56

Как запустить: 1. Скачайте файл. 2. Разрешите ему запускаться: правой кнопкой → Свойства → «Разрешить выполнение как программы», или в терминале: chmod +x lambit2FA-1.1-linux-x86_64.AppImage. 3. Откройте его. Ничего не устанавливается — программа в одном файле. Чтобы удалить, сотрите файл; коды останутся в ~/.config/lambit2FA.

Работает на Ubuntu 22.04 и новее, Debian 12 и новее, Linux Mint 21 и новее, Pop!_OS 22.04 и новее, Fedora 38 и новее. Другие дистрибутивы не проверялись. Если файл не открывается, поставьте libfuse2: sudo apt install libfuse2 (на Ubuntu 24.04: libfuse2t64).

При первом запуске система может спросить пароль от связки ключей «login». Это спрашивает система, а не программа: программа кладёт свой ключ в связку ключей системы. Введите пароль связки или нажмите «Отмена» — тогда ключ будет храниться в файле, привязанном к этому компьютеру и вашему пользователю.

Для чтения QR‑кода с экрана на Wayland нужна программа снимка экрана (gnome-screenshot, spectacle или grim). Если её нет — сделайте снимок сами и откройте его в программе как картинку.

Проверка скачанного: sha256sum lambit2FA-1.1-linux-x86_64.AppImage — результат должен совпасть с файлом .sha256 рядом.
